# Sunith Style Portfolio

Personal portfolio website with a retro sketch aesthetic: warm cream background, thick near-black hand-drawn borders, hard offset drop shadows, and pixel display typography.

## Tech Stack

- **Framework**: Next.js (App Router)
- **Language**: TypeScript (strict mode enabled)
- **Styling**: Tailwind CSS
- **Typography**: Google Fonts (`Press Start 2P` for headings, `JetBrains Mono` for body)
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Code Quality**: ESLint + Prettier (conflict-free)

## Getting Started

### Development

Start the local development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Verification Route

Visit [http://localhost:3000/design-system](http://localhost:3000/design-system) to view the design system tokens and reusable UI primitives.

### Build

Create a production build:

```bash
npm run build
```

### Production Start

Run the built application:

```bash
npm run start
```

### Linting & Formatting

```bash
npm run lint
npx prettier --check .
```
